# NOBODY - архив последнего адресата

**NOBODY** - интерактивная текстовая игра в жанре психологического детектива с элементами мистики и цифрового нуара.

действие происходит в небольшом промышленном городе в октябре 2009 года. главный герой - Яков Чернов, 24-летний сотрудник технического отдела городской службы связи.

на его столе появляется старый жёсткий диск из закрытой телефонной станции. на нём обнаруживается архив переписок, контактов и документов, часть которых не должна была существовать.

## сюжет

Яков начинает исследовать архив и постепенно замечает странные несоответствия:

- сообщения датированы временем, не совпадающим с датами их создания;
- один из участников переписки официально умер за три года до появления архива;
- отключённая телефонная линия продолжает отправлять сообщения;
- среди контактов обнаруживается имя самого ильи.

каждая новая находка ставит под сомнение достоверность происходящего.

## основные возможности

текущая версия игры включает:

- главное меню;
- текстовое повествование с последовательными игровыми сценами;
- исследование содержимого старого архива;
- просмотр переписок и контактных записей;
- изучение дат и метаданных файлов;
- несколько вариантов действий и переходов между сценами;
- финал первой главы.

## структура проекта

```text
NOBODY/
├── src/
│   └── nobody/
│       ├── Main.java
│       └── ui/
│           └── MainWindow.java
├── resources/
├── out/
└── README.md
```

- `Main.java` - точка входа в приложение.
- `MainWindow.java` - главное окно, интерфейс, игровые сцены и переходы между ними.
- `resources/` - каталог для игровых ресурсов.
- `out/` - каталог с результатами компиляции.

## запуск проекта

для запуска необходим установленный JDK 25 или совместимая версия Java.

откройте терминал в корневой папке проекта и выполните:

**1. создайте каталог для скомпилированных файлов:**

```powershell
New-Item -ItemType Directory -Force out
```

**2. скомпилируйте исходный код:**

```powershell
javac -encoding UTF-8 -d out src/nobody/Main.java src/nobody/ui/MainWindow.java
```

**3. запустите игру:**

```powershell
java -cp out nobody.Main
```

## особенности проекта

NOBODY использует минималистичный тёмный интерфейс с моноширинной типографикой и сдержанной цветовой палитрой.

основное внимание уделяется повествованию, исследованию цифровых следов и постепенному раскрытию истории через сообщения, документы и несоответствия в архивных данных.
